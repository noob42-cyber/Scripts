# Contributing

Thank you for your interest in contributing to **Scripts**.

Scripts is a learning-focused repository containing small Python
implementations of cryptography, encoding, and cybersecurity concepts.

Contributions are welcome, especially those that improve correctness,
clarity, documentation, or educational value.

## Before Contributing

Please:

- Read the repository README.
- Check existing issues and pull requests before starting work.
- Keep contributions relevant to the purpose of the repository.
- Prefer simple, readable implementations over unnecessary complexity.
- Do not submit code containing passwords, API keys, tokens, private keys,
  or other sensitive information.

## What You Can Contribute

Examples of useful contributions include:

- New educational scripts.
- Bug fixes.
- Improvements to existing implementations.
- Documentation and README improvements.
- Explanations of mathematical or security concepts.
- Examples and usage instructions.
- Tests for existing functionality.

## Adding a New Script

When adding a script:

1. Create a dedicated directory for the script.
2. Use a clear and descriptive filename.
3. Include a README explaining:
   - What the script does.
   - The underlying concept.
   - How the implementation works.
   - How to run it.
   - An example of its usage.
   - Relevant limitations.
4. Keep dependencies to a minimum.
5. Make sure the code is readable and reasonably documented.
